# Student Information Form

A simple browser-based app for adding student names, ages, and departments to a list. You can remove students and see the current student count.

## Features

- Add a student with a name, age, and department
- Show an error message when a required field is missing
- Delete a student from the list
- Display the number of students currently listed

## Files

- `index.html` — the page structure and styling
- `script.js` — form validation and student-list behavior

## Run the project

1. Keep `index.html` and `script.js` in the same folder.
2. Open `index.html` in a web browser.
3. Enter the student details and select **Submit**.

No installation or build tools are required.
